# Textual

Render and customize rich attributed text in SwiftUI.

[Documentation](https://swiftpackageindex.com/adamtheturtle/textual/documentation/textual) |
[Swift Package Index](https://swiftpackageindex.com/adamtheturtle/textual)

## Installation

```swift
.package(url: "https://github.com/adamtheturtle/textual.git", from: "0.5.1")
```

Add the `Textual` product to your target dependencies.

## Product

- `Textual`: SwiftUI views and styling APIs for inline and structured attributed text.

## Requirements

- Swift 6.0+
- macOS 15+, iOS 18+, tvOS 18+, watchOS 11+, or visionOS 2+
